## Overview

Personal portfolio showcasing my AI/ML projects, research, and professional profile. Features an integrated AI chatbot (BERU), downloadable CV, and detailed project cards with accuracy metrics and live demo links.

**Live at:** [varun-kumar-ds.github.io](https://varun-kumar-ds.github.io)

## Features

| Feature | Description |
|---------|-------------|
| Project showcase | 7 project cards with accuracy metrics, tech stacks, and links |
| BERU chatbot | Integrated AI assistant powered by LLaMA 3.3 70B via Groq |
| CV download | One-click PDF download |
| AI roadmap | Interactive AI Engineer learning roadmap section |
| Responsive design | Mobile-friendly layout |

## Tech Stack

| Component | Technology |
|-----------|-----------|
| Structure | HTML5 |
| Styling | CSS3, responsive media queries |
| Interactivity | Vanilla JavaScript |
| Hosting | GitHub Pages |
| Chatbot backend | Flask + Groq API (separate repo) |

## Local Development

```bash
git clone https://github.com/Varun-Kumar-DS/varun-kumar-ds.github.io.git
cd varun-kumar-ds.github.io
# Open index.html in a browser, or use a local server:
python -m http.server 8000
```
